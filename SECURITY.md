# Security policy

Open Playroom has no server, no accounts and no network access, so the attack surface is small: the app itself and the release pipeline (signing keys, store credentials).

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://github.com/tvgenechten/open-playroom/security/advisories/new). You will get an answer within a week.

Only the latest release in the stores is supported.
