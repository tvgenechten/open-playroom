# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, assume good intent, and remember who the app is for.

Report unacceptable behaviour privately to the maintainers through [GitHub's private reporting](https://github.com/tvgenechten/open-playroom/security/advisories/new) (choose "code of conduct" in the title). Reports are handled confidentially.
